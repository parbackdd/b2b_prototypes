# Incident Report Drafting Prototype

A non-production concept prototype for AI-assisted incident report drafting. All displayed names, incidents, customers, and operational data are synthetic; the site is not connected to production systems and must not be used for real incident handling.

## Run locally

Serve the repository root with any static HTTP server, for example:

```sh
python3 -m http.server 8000
```

Then open http://localhost:8000/.
